# 線上投保系統互動時序

## 系統間互動

```mermaid
sequenceDiagram
    autonumber
    actor C as 要保人
    participant W as 官網投保平台
    participant U as 核保系統
    participant R as 再保系統
    participant P as 金流閘道

    C->>W: 填寫要保書
    W->>U: 送出核保申請
    activate U
    U->>U: 自動核保規則檢核
    alt 符合自動核保條件
        U-->>W: 核保通過（即時）
    else 需人工審核
        U->>U: 派工至核保員
        Note over U: SLA：1 個工作日
        U-->>W: 待審核通知
    end
    deactivate U

    opt 保額超過自留額
        U->>R: 洽詢再保條件
        R-->>U: 回覆再保接受度
    end

    W->>P: 產生繳費連結
    P-->>C: 導向繳費頁面
    C->>P: 完成付款
    P-->>W: 付款成功通知
    W->>U: 觸發保單製作
    U-->>C: 寄送電子保單
```

第 12 頁 / 共 45 頁　　國泰產物保險股份有限公司　機密文件

## 服務水準（SLA）

| 環節 | 目標時間 | 監控方式 |
| --- | --- | --- |
| 自動核保回覆 | < 3 秒 | APM 監控 |
| 人工核保派工 | < 1 工作日 | 系統派工佇列 |
| 電子保單寄送 | 付款後 30 分鐘內 | 寄送成功率報表 |
