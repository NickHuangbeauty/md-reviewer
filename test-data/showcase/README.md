# md-reviewer 複雜案例展示包（10 件）

用 md-reviewer 的「匯入狀態」載入 `showcase-10-cases.json` 即可一次取得全部 10 份。

每份都同時做到：**展示渲染能力** + **內含真實解析瑕疵供審核**。

01. 01_車險理賠作業流程.md
    流程圖 + |||殘留 + 句子截斷
02. 02_核保分層負責表.md
    複雜合併表：第6列少一格(8→7)、1億以上列多一格
03. 03_RAG系統導入時程.md
    甘特圖 + 里程碑表
04. 04_理賠統計分析.md
    長條+折線圖、圓餅圖；圖表數字與表格占比不一致(45200/95500=47.3% vs 表列42%)
05. 05_線上投保系統時序.md
    時序圖；頁首頁尾殘留混入內文
06. 06_保單狀態與費率計算.md
    狀態機 + KaTeX 行內與區塊公式
07. 07_保單資料模型.md
    ER 圖(屬性名須英數,中文放註解)+ 亂碼(替換字元)
08. 08_客戶體驗地圖.md
    客戶旅程圖 + 心智圖
09. 09_風險評估與資金流.md
    四象限圖 + 資金流(flowchart，因 sankey 不支援中文)
10. 10_解析瑕疵綜合案例.md
    瑕疵大全：|||、表格缺格、頁碼混入、句子截斷、亂碼、raw JSON 殘留
