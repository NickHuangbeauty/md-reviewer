# 產險客戶體驗地圖

## 一、投保到理賠的客戶旅程

```mermaid
journey
    title 車險客戶完整旅程（滿意度 1-5 分）
    section 投保前
      看到廣告/推薦: 3: 客戶
      線上試算保費: 4: 客戶
      比較各家方案: 2: 客戶
    section 投保
      填寫要保書: 3: 客戶, 業務員
      等待核保結果: 2: 客戶
      繳費: 4: 客戶
      收到電子保單: 5: 客戶
    section 保單存續
      年度續保提醒: 4: 客戶, 系統
      辦理批改: 2: 客戶, 客服
    section 出險理賠
      事故通報: 2: 客戶, 客服
      現場查勘: 3: 客戶, 理賠員
      文件補齊: 1: 客戶
      理賠給付: 4: 客戶
      結案回訪: 4: 客戶, 客服
```

## 二、痛點盤整（心智圖）

```mermaid
mindmap
  root((產險客戶痛點))
    投保階段
      條款難懂
        專有名詞多
        除外責任藏在附約
      試算與實收不符
      核保等待久
    保單存續
      批改流程繁瑣
        需臨櫃
        重複填資料
      續保通知太晚
    理賠階段
      文件要求不明確
        反覆補件
        紙本正本要求
      查勘時間難配合
      理賠進度不透明
    數位服務
      App 功能分散
      客服等待時間長
      知識庫答案過時
```
